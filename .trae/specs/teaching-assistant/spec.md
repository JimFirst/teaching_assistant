# 教师助手系统需求规格说明书

## 一、项目概述

### 1.1 项目背景

随着教育信息化的推进，教师需要一款便捷的系统来管理班级、学生和作业。本系统旨在为教师提供一个集成化的教学管理工具，实现班级管理、学生管理和作业管理的数字化。

### 1.2 项目目标

- 提供统一的用户认证和权限管理
- 支持班级、学生的完整CRUD操作
- 实现作业的发布、提交、批改全流程
- 支持图片上传和大模型识别

## 二、技术栈

- **前端**: React + Antd + TypeScript + Vite
- **后端**: Node.js + Express + TypeScript + Sequelize + MySQL

## 三、用户角色

| 角色       | 描述               | 权限范围                               |
| ---------- | ------------------ | -------------------------------------- |
| 超级管理员 | 系统内置管理员     | 用户管理、全部功能                     |
| 教师       | 普通用户           | 班级管理、学生管理、作业管理、作业批改 |
| 学生       | 查看作业、提交作业 | 查看个人作业、提交作业                 |

## 四、功能需求

### 4.1 登录功能

#### 4.1.1 用户登录

- **需求描述**: 用户通过用户名和密码登录系统
- **输入**: 用户名、密码
- **输出**: 登录成功跳转首页，失败提示错误信息

#### 4.1.2 会话管理

- **需求描述**: 登录后保持会话状态
- **实现方式**: Session/JWT方式

### 4.2 超级管理员功能

#### 4.2.1 内置超级管理员账号

- **需求描述**: 系统预设超级管理员账户
- **默认账号**: admin / admin123

#### 4.2.2 用户管理

- **需求描述**: 超级管理员可以添加、编辑、删除普通用户
- **功能**:
  - 新增用户（设置用户名、密码、角色）
  - 编辑用户信息
  - 删除用户
  - 查看用户列表

### 4.3 班级管理功能

#### 4.3.1 班级列表

- **需求描述**: 查看所有班级
- **显示内容**: 班级名称、班级描述、创建时间、学生数量

#### 4.3.2 新增班级

- **输入**: 班级名称、班级描述
- **验证**: 班级名称不能为空且不能重复

#### 4.3.3 编辑班级

- **输入**: 班级名称、班级描述
- **验证**: 班级名称不能重复

#### 4.3.4 删除班级

- **验证**: 删除前检查是否有关联学生，若有提示先删除学生

### 4.4 学生管理功能

#### 4.4.1 学生列表

- **需求描述**: 在指定班级下查看学生列表
- **显示内容**: 学生姓名、学号、联系方式

#### 4.4.2 新增学生

- **输入**: 学生姓名、学号、联系方式
- **验证**: 学号在同一班级内不能重复

#### 4.4.3 编辑学生

- **输入**: 学生姓名、学号、联系方式

#### 4.4.4 删除学生

- **验证**: 删除学生时关联的作业提交记录一并删除

### 4.5 作业管理功能

#### 4.5.1 发布作业

- **需求描述**: 教师为指定班级发布作业
- **输入**: 作业标题、作业内容、截止日期、指向班级、图片上传
- **验证**: 作业标题不能为空
- **图片识别**: 上传作业图片后，通过大模型识别成文本保存问题和答案

#### 4.5.2 作业列表

- **需求描述**: 查看作业列表（按班级筛选）
- **显示内容**: 作业标题、发布班级、截止日期、创建时间

#### 4.5.3 编辑作业

- **输入**: 作业标题、作业内容、截止日期、图片上传

#### 4.5.4 删除作业

- **验证**: 删除作业时关联的问题、答案、提交记录一并删除

#### 4.5.5 作业详情

- **需求描述**: 查看作业详细信息
- **显示内容**: 作业标题、作业内容、截止日期、问题列表、答案列表

#### 4.5.6 学生查看作业

- **需求描述**: 学生只能查看自己班级的作业
- **显示内容**: 作业标题、作业内容、截止日期、问题列表

#### 4.5.7 作业提交

- **需求描述**: 学生提交作业答案
- **输入**: 作业ID、学生ID、答案内容
- **显示内容**: 提交记录列表

#### 4.5.8 作业批改

- **需求描述**: 教师批改学生作业
- **输入**: 提交记录ID、批改意见、分数
- **自动批改**: 基于大模型自动批改答案
- **显示内容**: 提交记录、批改结果、分数

## 五、数据模型

### 5.1 用户表 (users)

| 字段       | 类型         | 说明                          |
| ---------- | ------------ | ----------------------------- |
| id         | INTEGER      | 主键，自增                    |
| account    | VARCHAR(50)  | 账号（登录用户名），唯一      |
| username   | VARCHAR(50)  | 用户名（中文名字）            |
| password   | VARCHAR(255) | 密码（加密存储）              |
| role       | VARCHAR(20)  | 角色：admin/teacher/student   |
| subject    | VARCHAR(20)  | 学科：语文/数学/英语/科学     |
| created_at | DATETIME     | 创建时间                      |

### 5.2 班级表 (classes)

| 字段        | 类型          | 说明                |
| ----------- | ------------- | ------------------- |
| id          | INTEGER       | 主键，自增          |
| name        | VARCHAR(100)  | 班级名称，唯一      |
| description | TEXT          | 班级描述            |
| teacher_ids | TEXT          | 绑定教师ID列表（JSON数组） |
| created_at  | DATETIME      | 创建时间             |

### 5.3 学生表 (students)

| 字段       | 类型        | 说明                         |
| ---------- | ----------- | ---------------------------- |
| id         | INTEGER     | 主键，自增                   |
| name       | VARCHAR(50) | 学生姓名                     |
| student_no | VARCHAR(50) | 学号                         |
| phone      | VARCHAR(20) | 联系方式                     |
| class_id   | INTEGER     | 所属班级，外键               |
| user_id    | INTEGER     | 关联用户ID，外键（学生账号） |
| created_at | DATETIME    | 创建时间                     |

### 5.4 作业表 (homeworks)

| 字段       | 类型         | 说明           |
| ---------- | ------------ | -------------- |
| id         | INTEGER      | 主键，自增     |
| title      | VARCHAR(200) | 作业标题       |
| content    | TEXT         | 作业内容       |
| deadline   | DATETIME     | 截止日期       |
| class_id   | INTEGER      | 所属班级，外键 |
| image_url  | VARCHAR(500) | 作业图片路径   |
| created_at | DATETIME     | 创建时间       |

### 5.5 问题表 (questions)

| 字段           | 类型     | 说明                       |
| -------------- | -------- | -------------------------- |
| id             | INTEGER  | 主键，自增                 |
| homework_id    | INTEGER  | 作业ID，外键               |
| question_text  | TEXT     | 问题文本（大模型识别生成） |
| question_order | INTEGER  | 问题顺序                   |
| created_at     | DATETIME | 创建时间                   |

### 5.6 答案表 (answers)

| 字段        | 类型     | 说明                       |
| ----------- | -------- | -------------------------- |
| id          | INTEGER  | 主键，自增                 |
| question_id | INTEGER  | 问题ID，外键               |
| answer_text | TEXT     | 答案文本（大模型识别生成） |
| created_at  | DATETIME | 创建时间                   |

### 5.7 作业提交表 (submissions)

| 字段         | 类型     | 说明                   |
| ------------ | -------- | ---------------------- |
| id           | INTEGER  | 主键，自增             |
| homework_id  | INTEGER  | 作业ID，外键           |
| student_id   | INTEGER  | 学生ID，外键           |
| answers      | TEXT     | 提交的答案（JSON格式） |
| submitted_at | DATETIME | 提交时间               |

### 5.8 批改记录表 (grades)

| 字段          | 类型     | 说明             |
| ------------- | -------- | ---------------- |
| id            | INTEGER  | 主键，自增       |
| submission_id | INTEGER  | 提交记录ID，外键 |
| score         | INTEGER  | 分数             |
| feedback      | TEXT     | 批改意见         |
| graded_at     | DATETIME | 批改时间         |

## 六、非功能需求

### 6.1 安全性

- 密码加密存储
- 敏感操作需要登录验证

### 6.2 界面要求

- 使用React + Antd组件库
- 简洁清晰的操作界面
- 必要的表单验证和错误提示

### 6.3 图片处理

- 支持作业图片上传
- 大模型自动识别图片内容
- 提取问题和答案文本
